# Säkerhet

Publicera inte en sårbarhet som kan påverka användare av en omodifierad KW520
innan en rimlig möjlighet till samordnad rapportering har getts. Öppna inte ett
publikt issue med hemligheter, firmwaredumpningar eller personuppgifter.

För projektets egna verktyg kan vanliga, icke-känsliga buggar rapporteras via
GitHub Issues.

All användning sker på egen risk. Verktyget gör ingen bedömning av om en
firmwareändring är elektriskt eller termiskt säker.
